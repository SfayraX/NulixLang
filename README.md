# Nulix

Один язык на весь стек — от приложений до ядра ОС и голого железа. Программа описывает, что сделать, а Nulix решает, как выполнить это на конкретной машине, и специализирует программу под её возможности как можно позже.

## Состояние

Проект перезапущен 14 ноября 2026 года: язык перепроектирован, реализация начинается с нуля. Компилятор начат: готов лексер. В репозитории лежат формальная грамматика, описание ядра IR и начало компилятора на Rust.

Прежний прототип v0.2 удалён из дерева и остаётся в истории git.

## Грамматика

- [spec/grammar.md](spec/grammar.md) — лексика, приоритеты и полный текст правил; принято 15 ноября 2026.
- [grammar/nulix.lark](grammar/nulix.lark) — те же правила в виде, который читает проверка.
- Проверка: `pip install lark`, затем `python3 tools/grammar/check.py grammar`. Она собирает грамматику как LALR(1) в строгом режиме, где любой конфликт — ошибка, и разбирает примеры из папки `grammar`. Проверка написана на Python и нужна, пока нет разборщика на Rust.
- Документ пересобирается командой `python3 tools/grammar/build_doc.py grammar spec/grammar.md`.

## Ядро IR

[spec/ir-core.md](spec/ir-core.md) — устройство переносимого Nulix IR: решения, примеры и порядок реализации. Принято 16 ноября 2026; машинной проверки у него пока нет, она появится с реализацией.

## Компилятор

- `compiler/` — начальный компилятор на Rust. Пока в нём только лексер.
- Тесты: `cd compiler && cargo test`. Тест сверяет лексер на Rust с проверочным лексером на Python по файлу `grammar/tokens.golden.tsv`: на каждом примере лексемы обязаны совпасть.
- Эталон пересобирается командой `python3 tools/grammar/dump_tokens.py grammar > grammar/tokens.golden.tsv`.
- Посмотреть лексемы файла: `cd compiler && cargo run -- lex ../grammar/samples/03-скрипт.nx`.
- Правила кода: без `unsafe`, без собственных макросов и без внешних зависимостей, чтобы перенос на Nulix был почти построчным.
